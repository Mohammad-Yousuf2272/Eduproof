
# Professional Secure Educational Verification System

## Features
- Modern UI
- User Authentication
- RSA Digital Signatures
- SHA-256 Verification
- Audit Logs
- QR Verification
- PDF/TXT/DOCX Support
- Tamper Detection

## Installation

pip install -r requirements.txt

## Run

python app.py

## Open

http://127.0.0.1:5000
